# Deutsch für Ali · A1 → B1

Сайт-тренажёр немецкого: **36 уроков** от A1 до B1 с заданиями, монетами, магазином, достижениями, рейтингом и живым голосовым собеседником — **Мией**.

Живёт в интернете: статика на **Netlify**, данные в **Supabase**. Аккаунты, вход, восстановление пароля, личный кабинет, общая таблица рейтинга. Заходишь с любого компьютера или телефона и продолжаешь с того же места.


<sub>**In English** — A German course for one real person, built from scratch: 36 levels from A1 to B1, a voice tutor powered by Claude, spaced repetition, five mini-games and a leaderboard. No framework and no build step — vanilla ES modules served statically from Netlify, with Supabase (Postgres + Auth + Storage) behind it and two serverless functions holding the only secrets. Roughly 5 800 lines of German audio are synthesised once and served from a content-addressed CDN cache, so the synthesis function is only ever called for something new. Course content is machine-validated (structure, answer keys, German/Russian consistency) and the offline conversation engine has 138 regression tests. Documentation below is in Russian — it is written for the person the app was built for.</sub>

## Уровни

| Блок | Уроки | Про что |
|---|---|---|
| **A1** · Начальный | 1–12 | Познакомиться, посчитать, купить хлеб, доехать, объясниться у врача |
| **A2** · Базовый | 13–24 | Снять квартиру, найти работу, прописаться, сходить в ресторан, поговорить о семье |
| **B1** · Уверенный | 25–36 | Работать, подписывать договоры, признать диплом, спорить, рассказывать о себе на экзамене |

Уровень не назначается сверху: он **зарабатывается**. Сдал последний урок A1 — стал A2. При первом запуске сайт спрашивает, сколько немецкого уже есть, и открывает курс с нужного места; поменять можно в кабинете в любой момент. Мия читает этот уровень и говорит по-немецки ровно на нём.

## Аккаунт и рейтинг

Можно заниматься и без регистрации — тогда прогресс лежит на этом компьютере, как раньше. С аккаунтом он привязан к почте, а ты попадаешь в общую таблицу: опыт, серия дней, пройденные уроки, выученные слова и отдельный рейтинг по каждой мини-игре. Показываться в таблице или нет — переключатель в кабинете.

Пароли хранятся только у себя (scrypt + соль), сессия — подписанная HttpOnly-кука на 90 дней. Аккаунты лежат в `data/users/`, по файлу на человека.

## Как это развёрнуто

Сайт — статические файлы. Никакой сборки, никакого сервера: Netlify раздаёт `public/`, всё
остальное делают Supabase и две маленькие функции.

| Что | Где живёт |
|---|---|
| Страницы, стили, весь курс | статика на Netlify |
| Регистрация, вход, восстановление пароля | Supabase Auth — браузер ходит туда напрямую |
| Прогресс и рейтинг | Supabase Postgres, защита на уровне строк |
| Голос Мии | Supabase Storage (CDN) + функция `tts` только для новых фраз |
| Свободный разговор | функция `tutor` → Claude (ключ лежит в переменных Netlify) |

Почему так: прогресс и аккаунты идут из браузера прямо в Supabase, потому что защищают данные
правила на строках, а не посредник. Ключи Claude и service-ключ Supabase в браузер не попадают
никогда — они есть только внутри функций.

## Что нужно сделать один раз

### 1. Supabase

1. Создай проект на [supabase.com](https://supabase.com) (Free-тариф хватает с запасом).
2. **SQL Editor** → вставь целиком `supabase/migrations/0001_init.sql` → Run.
   Это создаёт таблицы, правила доступа, функцию рейтинга и бакет для голоса.
3. **Authentication → Providers → Email**: включён по умолчанию. Реши, нужно ли подтверждение
   почты («Confirm email»). С ним надёжнее, без него регистрация на один шаг короче.
4. **Authentication → URL Configuration**: в *Site URL* впиши адрес сайта на Netlify, а в
   *Redirect URLs* добавь его же и `…/#/password` — иначе ссылка «забыл пароль» приведёт не туда.
5. **Settings → API**: скопируй *Project URL*, ключ *anon* и ключ *service_role*.

### 2. Netlify

1. Подключи репозиторий (или перетащи папку в Netlify Drop).
   Собирать нечего: `publish = public`, это уже прописано в `netlify.toml`.
2. **Site configuration → Environment variables** — добавь:

   | Переменная | Значение |
   |---|---|
   | `SUPABASE_URL` | Project URL |
   | `SUPABASE_ANON_KEY` | ключ anon |
   | `SUPABASE_SERVICE_ROLE_KEY` | ключ service_role |
   | `ANTHROPIC_API_KEY` | ключ Claude (без него Мия работает офлайн) |

3. Задеплой. Открой сайт — если всё сошлось, на экране входа появятся поля регистрации.

### 3. Голос (один раз, локально)

Все фразы курса — а это около 5800 реплик — синтезируются заранее и кладутся в бакет. После этого
браузер берёт их прямо с CDN: мгновенно, бесплатно и без единого вызова функции.

```bash
cp .env.example .env     # вписать SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY
npm install
npm run audio            # 20–40 минут, можно прерывать и запускать снова
```

Готовые фразы пропускаются, так что повторный запуск догоняет только новое — например, после
добавления уровня. Функция `tts` остаётся нужна лишь для того, что Мия придумывает на ходу.

## Работа с кодом

```bash
npm run dev       # netlify dev — всё как на проде: функции, переменные, редиректы
npm run preview   # только интерфейс, без функций и базы (быстро, для вёрстки)
npm run check     # 36 уровней через валидатор + тесты офлайн-мозга
```

Для `npm run dev` нужен Netlify CLI: `npm i -g netlify-cli`, потом `netlify link`.


## Мия — собеседник, а не урок

Мия говорит **живым нейросетевым голосом** (Seraphina), а не роботом из браузера. Голос работает сразу, ключ для него не нужен: сервер сам синтезирует речь и кэширует её в `data/tts-cache`, поэтому уже услышанные фразы звучат мгновенно.

Главное правило: **она отвечает на том языке, на котором с ней заговорили**. Написал по-русски — ответит по-русски, нормальным живым текстом, а не немецкой фразой с переводом под ней. Темы любые: работа, машина, дети, деньги, футбол, немецкая бюрократия, что подарить на день рождения. Она не превращает каждую реплику в урок и не исправляет русский.

Немецкий начинается тогда, когда его попросят:

* «как будет …», «что значит …» — объяснит слово с примером и вернётся к разговору;
* «давай на немецком» — переключится целиком, и интерфейс переключится вместе с ней (кнопка 💬 / 🇩🇪, микрофон, подсказка в поле ввода);
* написал ей по-немецки — ответит по-немецки и мягко поправит ошибку.

Переключить режим можно и руками — кнопкой рядом с настройками. Немецкий она держит на твоём уровне CEFR: на A1 это три коротких предложения в настоящем времени, на B1 — нормальная речь с придаточными и пассивом.

Голос **нейросетевой** (Seraphina), женский, и работает сразу без всякого ключа: сервер синтезирует речь сам и кэширует её в `data/tts-cache`. Свободный разговор на любые темы требует ключ Anthropic — без него Мия остаётся, но отвечает из офлайн-словаря и честно об этом предупреждает.

Тембр настраивается в Профиле: четыре варианта от «Мягкий» (по умолчанию — тихо и спокойно) до «Чёткий». Нажимаешь вариант — Мия тут же говорит фразу этим голосом на обоих языках, выбираешь тот, что приятнее на слух. Там же можно сменить сам голос: Seraphina, Amala, Katja и два с акцентом.

Два режима:

- **Офлайн** (по умолчанию, работает сразу): у Мии есть собственный локальный разговорный движок. Она понимает, что Али сказал по-русски или по-немецки, отвечает на вопросы о значении любого из пройденных слов, объясняет любую грамматику курса, рассказывает про Германию и про сам сайт, поддерживает разговор на бытовые темы и делится историями из своей жизни в Берлине. Ключ не нужен.
- **AI-режим**: Мия отвечает на любые реплики, поддерживает разговор на любую тему, помнит, что Али рассказывал раньше, и мягко исправляет ошибки. Включается **прямо на сайте**: на главной (или в Профиле) есть поле «Включить умную Мию» — вставить туда ключ Anthropic и нажать кнопку. Сайт сам проверит ключ, сохранит его и включит режим. Ничего перезапускать не нужно.

## Панель управления

Первый зарегистрировавшийся становится админом — сайт делает это сам, чтобы не было промежутка,
когда пользователи есть, а управлять ими некому. У него в кабинете появляется кнопка **⚙️ Панель**
(`#/admin`), остальные её не видят, а функция за ней всё равно проверяет права на каждом запросе.

Внутри:

* **Ключ Anthropic** — можно вставить прямо здесь. Сайт сначала проверит его у Anthropic и только
  потом сохранит; в браузер ключ не возвращается никогда, видно лишь «есть / нет». Если задана
  переменная `ANTHROPIC_API_KEY` в Netlify — она главнее, и поле прячется.
* **Люди** — кто зарегистрирован, уровень, опыт, когда заходил. Можно заблокировать (исчезает из
  рейтинга и теряет доступ) или выдать права админа.
* **Цифры** — сколько всего, сколько заходили сегодня и за неделю.

## Фильтр содержимого

Работает всегда, выключить нельзя. Сообщение проверяется **до** обращения к Claude — и в браузере,
и на сервере — поэтому запрещённое отвечается мгновенно и не стоит ни копейки.

Отсекается: порнография и эротика, азартные игры и ставки, расизм и вражда, насилие и оружие,
наркотики, партийная политика и войны. Плюс сама Мия не ругается, не повторяет оскорбления и не
переходит на личности, даже если на неё перешли.

Фильтр намеренно узкий. «Как будет …» и «что значит …» не блокируются: спросить перевод грубого
слова — это словарь, а не нарушение. Разговор о том, как устроены ведомства, страховка, договоры
и гражданство, политикой не считается — это ровно то, зачем человек и учит язык.

Если речь заходит о том, что человеку плохо и опасно, Мия бросает урок и даёт телефон доверия.


## Как устроен уровень

Слова (карточки + квиз) → Грамматика → 3 миссии заданий → Диалог (послушать и сыграть роль Али) → Разговор с Мией → **Экзамен** (10 заданий, нужно 70%).

Экзамен открывает следующий урок. После него открываются ещё два режима с Мией:

- **🎓 Устный экзамен** — Мия задаёт 5–7 вопросов по теме голосом, поправляет и объясняет по-русски.
- **💬 Разговор по теме** — свободная беседа вокруг пройденной темы, можно спрашивать что угодно.

## Разговор с Мией

**🎙️ Мия** в меню — это просто голосовой собеседник: она ничего не говорит, пока к ней не обратятся.
Нажми микрофон и говори. Под микрофоном кнопка **DE / RU** — она переключает язык, который слушает
микрофон (браузер умеет распознавать только один язык за раз), и выбор запоминается. **Написать**
можно на любом языке без переключения. Она отвечает по-немецки, а объясняет по-русски.

Ролевые сценарии уровней и устный экзамен — наоборот, начинает она: там у неё своя роль.

## Игры

**🎮 Игры** — пять коротких тренировок на словах уже открытых уровней, по паре минут каждая:

| Игра | Что тренирует |
| --- | --- |
| 🧩 Память | Находишь пары «немецкое слово ↔ перевод». Узнавание. |
| ⚡ Блиц | 60 секунд на скорость, серия подряд даёт больше очков. Беглость. |
| 🎯 der · die · das | 20 существительных, один тап. Артикли — самое слабое место. |
| 🔤 Анаграмма | Собрать слово из перемешанных букв по переводу. Написание. |
| 🎪 Виселица | Угадать слово по буквам, включая ä ö ü ß. Орфография. |

Игры дают немного XP и монет — заметно меньше уроков, чтобы оставаться перерывом, а не обходным
путём. Игра, для которой ещё мало слов, показана закрытой с объяснением, когда откроется.

## Игровая часть

Монеты за ответы, миссии, диалоги, экзамены и ежедневные заходы. В **Магазине**: подсказки, щит комбо, вторая попытка, XP-буст, рюкзак (+25% монет), кофе (+10% XP), словарь Мии (подсказки вдвое дешевле), титулы и темы оформления. Плюс достижения, серия дней и дневная цель XP.

## Где хранится прогресс

- **Таблица `progress` в Supabase** — весь прогресс одним JSON-объектом: XP, монеты, уровни,
  покупки, достижения, память слов. Одна строка на человека, читать и писать её может только он сам.
- **Копия в localStorage** — на случай, если интернет отвалился посреди занятия. При запуске
  берётся та версия, что новее.
- Если открыты две вкладки, побеждает та, что сохранила позже: сравнение происходит внутри одной
  транзакции в базе (`save_progress`), так что потерять заработанное нельзя.
- Без аккаунта прогресс живёт только в localStorage этого браузера. При регистрации сайт
  предлагает перенести его в новый аккаунт.
- В кабинете есть **Экспорт** и **Импорт** прогресса файлом.

### Начать с нуля

Удалить аккаунт в Supabase (**Authentication → Users**) — прогресс уходит вместе с ним.
Гостевой прогресс стирается очисткой данных сайта в браузере.


## Проверки


## Настройки под себя

В **Профиле**: звук, озвучка, живой голос (можно выключить и вернуться к голосу браузера), выбор голоса Мии, мягкость голоса, скорость речи, авто-микрофон, перевод, дневная цель, экспорт/импорт и сброс.

Сайт открывается с любого устройства по своему адресу — телефон, планшет, чужой компьютер. Прогресс привязан к аккаунту, а не к машине.
