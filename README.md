# Deutsch für Ali

Сайт для изучения немецкого — **36 уроков от A1 до B1**, с голосовым собеседником, интервальным
повторением, играми и рейтингом. Сделан для одного человека и доведён до состояния, когда им может
пользоваться кто угодно.

<sub>**In English** — A German course, 36 levels from A1 to B1: a voice tutor powered by Claude,
spaced repetition, a placement test, five mini-games and a leaderboard. No framework and no build
step — vanilla ES modules served as static files, with Postgres behind them. Course content is
machine-validated (structure, answer keys, German/Russian consistency) and the offline conversation
engine has 138 regression tests. The documentation below is in Russian: it is written for the
person this was built for.</sub>

---

## Что внутри

**36 уроков, три ступени.** A1 — знакомство, числа, семья, еда, дом, город, здоровье. A2 — жильё,
работа, врач, ведомства, покупки, транспорт. B1 — договоры, признание диплома, конфликты,
общество, экзамен. Каждый урок: слова с карточками → грамматика → три миссии заданий → диалог →
разговор с Мией → экзамен.

**Мия — собеседник, а не урок.** Она отвечает на том языке, на котором с ней заговорили: написал
по-русски — ответит по-русски, нормальным живым текстом. Темы любые: работа, машина, дети, деньги,
немецкая бюрократия. Немецкий начинается только когда попросят — «как будет…», «давай на немецком»
или если написать ей по-немецки. Говорит живым нейросетевым голосом и слушает через микрофон.

**Тест уровня.** Если человек не знает, с чего начинать — 18 вопросов, по шесть на ступень.
Ступень засчитывается при четырёх верных из шести и только если пройдены предыдущие. По результату
курс открывается с нужного урока, и Мия узнаёт, на каком немецком с ним говорить.

**Интервальное повторение.** Каждое встреченное слово помнит, когда его спросили и ошибся ли ты.
Забытое возвращается раньше, выученное — реже.

**Игры и рейтинг.** Пять мини-игр на уже открытых словах — память, блиц, анаграмма, виселица,
артикли. Общая таблица: опыт, серия дней, уроки, слова и отдельный рейтинг по каждой игре.

**Аккаунт.** Прогресс привязан к почте: заходишь с любого устройства и продолжаешь с того же
места. Без регистрации тоже работает — тогда прогресс живёт в браузере.

## Как сделано

Статический сайт: **vanilla ES modules, без фреймворков и без сборки**. Браузер грузит ровно те
файлы, которые лежат в `public/` — ничего не транспилируется и не бандлится.

| Слой | Чем |
|---|---|
| Страницы, стили, весь курс | статика |
| Аккаунты, прогресс, рейтинг | Postgres с защитой на уровне строк |
| Голос | нейросетевой TTS, синтезируется один раз и раздаётся с CDN |
| Свободный разговор | Claude |

Весь курс озвучен заранее — около 5800 реплик синтезируются разово и кладутся в хранилище, поэтому
в обычной работе браузер берёт звук прямо с CDN, а синтез вызывается только для того, что Мия
придумывает на ходу. Ключ кэша — хеш от текста и всех настроек голоса, один и тот же по обе
стороны.

## Локально

```bash
npm install
npm run preview   # интерфейс на http://localhost:4173, без базы и без ключей
npm run check     # 36 уроков через валидатор + тесты
```

`npm run check` прогоняет все файлы уроков по контракту из [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md) —
структура, типы заданий, ключи ответов, совпадение топонимов в немецком и русском — и 138 проверок
офлайн-движка Мии.

## Структура

```
public/js/app.js          роутер и экраны
public/js/backend.js      единственная дверь наружу
public/js/auth.js         вход, регистрация, восстановление пароля
public/js/placement.js    тест уровня
public/js/store.js        прогресс, XP, серия, достижения, уровень CEFR
public/js/exercises.js    движок заданий: 7 типов, подсказки, щит, вторая попытка
public/js/tutor.js        Мия: разговор, немецкий режим, устный экзамен, сценарии
public/js/speech.js       голос и распознавание речи
public/js/games.js        пять мини-игр
public/js/brain.js        офлайн-движок Мии, когда нет ключа
public/js/content/        36 уроков (levelNN.js)
tools/                    валидатор уроков, тесты, предгенерация звука
```
