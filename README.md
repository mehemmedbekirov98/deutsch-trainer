# Lingua Mia

Сайт для изучения немецкого — **36 уроков от A1 до B1**, с голосовым собеседником, интервальным
повторением, играми и рейтингом. Объясняет **по-русски или по-азербайджански**: язык переключается
целиком — интерфейс, уроки, игры и сама Мия.

<sub>**In English** — A German course, 36 levels from A1 to B1, explained in Russian or in
Azerbaijani: a voice tutor powered by Claude, spaced repetition, a placement test, five mini-games
and a leaderboard. No framework and no build step — vanilla ES modules served as static files, with
Postgres behind them. Course content is machine-validated (structure, answer keys, German/Russian
consistency) and the offline conversation engine has 138 regression tests. The documentation below
is in Russian.</sub>

---

## Что внутри

**36 уроков, три ступени.** A1 — знакомство, числа, семья, еда, дом, город, здоровье. A2 — жильё,
работа, врач, ведомства, покупки, транспорт. B1 — договоры, признание диплома, конфликты,
общество, экзамен. Каждый урок: слова с карточками → грамматика → три миссии заданий → диалог →
разговор с Мией → экзамен.

**Мия — собеседник, а не урок.** Она отвечает на том языке, на котором с ней заговорили: написал
по-русски — ответит по-русски, по-азербайджански — по-азербайджански, нормальным живым текстом.
Темы любые: работа, машина, дети, деньги, немецкая бюрократия. Немецкий начинается только когда
попросят — «как будет…», «давай на немецком» или если написать ей по-немецки. Говорит живым
нейросетевым голосом и слушает через микрофон. Без ключа Claude она отвечает из офлайн-словаря —
и он тоже понимает оба языка.

**Тест уровня.** Если человек не знает, с чего начинать — 18 вопросов, по шесть на ступень.
Ступень засчитывается при четырёх верных из шести и только если пройдены предыдущие. По результату
курс открывается с нужного урока, и Мия узнаёт, на каком немецком с ним говорить.

**Интервальное повторение.** Каждое встреченное слово помнит, когда его спросили и ошибся ли ты.
Забытое возвращается раньше, выученное — реже.

**Игры и рейтинг.** Пять мини-игр на уже открытых словах — память, блиц, анаграмма, виселица,
артикли. Общая таблица: опыт, серия дней, уроки, слова и отдельный рейтинг по каждой игре.

**Два языка объяснения.** Русский и азербайджанский. Немецкий при этом не трогается — он и есть
предмет. Переключатель в кабинете и на первом экране; выбор запоминается. Словари грузятся по
мере надобности: при заходе 39 КБ, а урок приносит свои 7 КБ, когда его открывают.

**Аккаунт.** Прогресс привязан к почте: заходишь с любого устройства и продолжаешь с того же
места. Какая копия новее, решает счётчик версий на сервере, а не часы устройства — телефон со
сбитыми часами ничего не затирает. Без регистрации тоже работает: прогресс живёт в браузере, а
при первом входе сайт предложит перенести его в аккаунт.

## Как сделано

Статический сайт: **vanilla ES modules, без фреймворков и без сборки**. Браузер грузит ровно те
файлы, которые лежат в `public/` — ничего не транспилируется и не бандлится.

| Слой | Чем |
|---|---|
| Страницы, стили, весь курс | статика |
| Аккаунты, прогресс, рейтинг | Postgres с защитой на уровне строк |
| Голос | нейросетевой TTS, синтезируется один раз и раздаётся с CDN |
| Свободный разговор | Claude |

Весь курс озвучен заранее — 35 260 клипов: три языка (немецкий, русский, азербайджанский) на
четыре тембра голоса. Тембр входит в ключ кэша, поэтому озвучен каждый: иначе человек, сменивший
голос в кабинете, терял всю предгенерацию разом и ждал синтеза на каждом слове. Синтезируются они
один раз и кладутся в хранилище, так что браузер берёт звук прямо с CDN, а функция вызывается
только для того, что Мия придумывает на ходу. Ключ кэша — хеш от текста и
всех настроек голоса, один и тот же по обе стороны; что они не разошлись, проверяет
`npm run audiocheck` — он считает ключ ровно так же, как браузер, и спрашивает хранилище.

**Сторонних скриптов на странице нет ни одного.** Supabase и шрифты лежат своими файлами в
`public/vendor` и `public/fonts`: код, исполняющийся рядом с полем пароля, может быть только
нашим, а адрес посетителя никуда не уходит. Content-Security-Policy это и закрепляет — `script-src
'self'`, `style-src 'self'`, `font-src 'self'`. Обновляются командами `npm run vendor` и
`node tools/vendor-fonts.mjs`.

## Локально

```bash
npm install
npm run preview   # интерфейс на http://localhost:4173, без базы и без ключей
npm run check     # всё, что проверяется без сети
```

После правки перевода словарь надо перерезать — `npm run split`, — иначе сайт будет отдавать
старые куски, а отчёт о полноте этого не увидит.

Проверки, которым нужна живая база и ключи (`.env`), — руками перед выкладкой:

```bash
npm run db           # права и видимость на живой базе: что видно анониму, что закрыто
npm run access       # заводит настоящий аккаунт, дёргает функции его токеном и удаляет
npm run audiocheck   # лежит ли в хранилище то, что попросит браузер
```

`npm run check` прогоняет все файлы уроков по контракту из [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md) —
структура, типы заданий, ключи ответов, совпадение топонимов в немецком и русском, — 164 проверки
офлайн-движка Мии и полноту перевода (`npm run i18n`: что осталось по-русски, что осиротело и где
перевод разошёлся с оригиналом по подстановкам, переводам строк или числам). Плюс то, что ловится
только целиком:

- **решаемость после перевода** — те же 1627 заданий прогоняются через словарь и проверяются
  заново: не слились ли два варианта ответа в один, не остался ли ключ русским, не поехало ли
  немецкое предложение (а с ним и его озвучка);
- **забытые импорты** — имя используется, но не ввезено. Синтаксис при этом верный, тесты
  зелёные, а экран молча сломан: так «умная» Мия однажды не работала вообще ни у кого;
- **секреты** — весь рабочий каталог и КАЖДЫЙ блоб в истории git. Ключ, попавший в коммит,
  остаётся там навсегда, и удалить файл следующим коммитом недостаточно;
- **голоса** — список, который принимает сервер, против выбора в кабинете;
- **имя** — подстановка имени ученика вместо учебного «Эмиля» на всех трёх языках.

## База

Схема лежит в `supabase/migrations/` и применяется по порядку — через `supabase db push` или
вставкой в SQL Editor. Шесть файлов, и каждый следующий чинит то, что нашлось в предыдущем:

| | Что делает |
|---|---|
| `0001_init` | профили, прогресс, рейтинг, бакет с голосом |
| `0002_admin` | админ по адресу почты, блокировка, настройки |
| `0003_lockdown` | никто не поднимает себя до админа; блокировка останавливает запись |
| `0004_limits` | счётчик расходов на Мию и озвучку, предел размера сейва, рейтинг не раздаёт чужие id, бакет не перечисляется |
| `0005_clock` | сбитые часы устройства больше не заклинивают сохранение навсегда |
| `0006_revisions` | какая копия новее, решает счётчик версий на сервере, а не часы браузера |

Что из этого действительно применено к живой базе, показывает `npm run db` — он проверяет не
текст миграций, а поведение: какой ответ получает аноним, что закрыто, что считается.
